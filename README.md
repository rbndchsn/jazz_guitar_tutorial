# Getting Out of ii–V–I

A jazz guitar reference for substituting every chord in a ii–V–I, worked in the key of C major. Four sheets, 140 chord diagrams, with scale degrees printed inside the dots.

**Live site:** https://rbndchsn.github.io/jazz_guitar_tutorial/

The site is five hand-authored static HTML files. Each page is completely self-contained — inline CSS, inline JavaScript, no assets. There is no build step. The only external dependency is Google Fonts.

## The sheets

- **[Twelve Ways Out of Dm7](1iichordDm7substitutions.html)** — the ii chord. Mostly addition rather than alteration: upper structures, sus voicings, borrowed minor, altered dominants, tritone subs.
- **[Twelve Ways Out of G7](2VchordG7substitutions.html)** — the V chord, where almost anything is legal: 13ths and ♭9s, sus and phrygian, the altered scale, the D♭7 tritone substitution, the backdoor B♭7.
- **[Living on the I Chord](3IchordCmaj7strategies.html)** — the tonic, in four parts: substitutions, chord melody, turnarounds and vamp devices, and pentatonics for soloing.
- **[Three Arrangements; Examples](4threearrangements.html)** — the first three sheets put to work on a single twelve-bar vamp, arranged three ways: a melody on the top string, a borrowed minor iv, then a chromatic turnaround. Every bar diagrammed with its melody note.

Everything is in standard tuning (E A D G B E), notated with the low string at left. No open strings are load-bearing, so every grip transposes by sliding.
